## About

I'm a computer science undergraduate interested in performance-oriented computing: how algorithms, memory hierarchies, parallel execution, and hardware architecture interact.

I build projects from scratch, study their underlying mathematics, and investigate how implementation choices affect correctness and speed.

My current direction is **GPU systems and efficient AI infrastructure**, with a focus on CUDA, numerical kernels, and eventually LLM inference.
